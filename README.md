# YA SELVA

The artist project. Wandering bard, sound collector, participatory performance.
Explorer archetype — Alan Lomax × Xavier Rudd; Paul Simon and Walt Whitman with an Ableton Push.

> **Ya Selva is Break This Loop in a bag. The portable version.**

> 🔒 **A moving musical center small enough to travel anywhere, porous enough to become larger through every place it touches.**
> **Ya Selva carries the spine. The ensemble lives in the world.**
>
> The locked master vision → [`docs/vision/master-vision.md`](docs/vision/master-vision.md)

## The five named things

| | what it is | presence |
|---|---|---|
| **BREAK THIS LOOP** | the movement, the platform, the archive | runs without him |
