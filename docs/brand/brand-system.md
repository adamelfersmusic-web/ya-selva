# Brand System — how the two identities connect

## The billing line

```
YA SELVA presents · a BREAK THIS LOOP night
```

Same structure as a festival or label brand. It is not decoration — it is where
"runs without him" becomes visible.

**The movement is the parent. The night is an instance.** Which means the event page
still works if a host runs one and Ya Selva isn't on it. Swap the artist name, keep
everything else. Presence-independence is encoded into the flyer.

## The color bridge

The connection wasn't invented — it was already there. Both palettes contain gold.
It is the only color they share, so it became the connective tissue.

```
YA SELVA   forest green · rust · ember orange · GOLD · lantern amber · black
BTL        black ink · cream paper · red block · GOLD/ochre glyph
```

Ember-orange to BTL red is a short walk on the same axis. One is lamplight,
the other is printed ink. Neighbors.

## The rule

```
SHARED     gold · amber · ochre        the connective tissue
BOTH       black                       the ground
YA SELVA   forest green · moss         his alone
BTL        cream paper · red block     its alone
```

The shared colors let a piece feel like it belongs to both.
The unshared ones are how you tell them apart at a glance — which you still need,
because they are a person and a place, not one brand.
