# YA SELVA — Design System

## Purpose

This is the canonical design-system reference for Ya Selva.

Use it whenever creating:

- posters
- vision boards
- social graphics
- visual manifestos
- tour graphics
- live-show graphics
- field-journal pages
- editorial layouts
- visual references for AI image generation
- repo-generated design artifacts

The goal is not to make every piece look identical.

The goal is to make every piece feel like it came from the same world.

> **Consistent motive. Variable expression.**

────────

## 1. Core visual thesis

Ya Selva should feel like:

> **a field journal, a travel artifact, a handmade manifesto, and a cinematic music documentary collided together.**

The visual language must remain:

- tactile
- human
- weathered
- cinematic
- poetic
- grounded
- mythic without becoming fantasy
- imperfect without becoming sloppy
- adventurous without becoming influencer-travel content

The work should feel found, carried, worn, written on, taped together, printed, handled, traveled with, and lived in.

It should never feel sterile.

────────

## 2. Design principle

The visual world should follow the same rule as the character:

> **Find the pulse. Follow it. Make something real. Leave the signal.**

Design should not become decoration detached from the life.

The visual system should feel like evidence that Ya Selva passed through somewhere.

────────

## 3. Core palette

Use a restrained, earthy palette.

### Primary neutrals

**Charcoal / near-black**

Use for:

- backgrounds
- large dark fields
- high-contrast sections
- grounding the composition

Approximate range:

- #17150F
- #1D1A14
- #242118

**Parchment / warm cream**

Use for:

- paper fields
- text on dark backgrounds
- torn-note surfaces
- manifesto blocks

Approximate range:

- #E8DDC7
- #D8CFBC
- #F0E6D2

**Kraft / aged tan**

Use for:

- collage scraps
- secondary paper textures
- labels
- weathered modules

Approximate range:

- #B89C74
- #A98C63
- #C4A77D

### Secondary earth tones

**Moss / olive**

Use sparingly for:

- clothing
- organic texture
- subtle blocks
- botanical or field references

Approximate range:

- #42493B
- #4D513F
- #5B5B45

**Rust / burnt brown**

Use for:

- secondary accents
- aged leather
- weathered marks

Approximate range:

- #7F4A30
- #8B4B2C

### Signature accent

**Ember orange**

This is the signal color.

Use for:

- the Ya Selva signal mark
- underline strokes
- small callouts
- directional marks
- stamps
- key emphasis
- rare highlights

Approximate range:

- #F05A18
- #FF5A00
- #E95016

The orange should feel like:

- ember
- flare
- spray paint
- beacon
- road marking
- signal

It should never dominate the whole page.

────────

## 4. Typography hierarchy

Typography should feel editorial, literary, analog, and slightly imperfect.

### A. Hero display

Use:

- oversized serif
- high-contrast serif
- literary display type
- occasionally large rough sans / painted lettering for titles

Characteristics:

- dramatic scale
- spacious
- confident
- poetic
- not corporate

Use for:

- YA SELVA
- major thesis
- archetype names
- manifesto statements

### B. Typewriter / mono / archival labels

Use for:

- section labels
- captions
- notes
- numbered modules
- field annotations
- archival metadata

Characteristics:

- plain
- utilitarian
- documentary
- slightly mechanical

This provides tension against the more romantic headline type.

### C. Handwritten / brush / marker annotation

Use sparingly.

Use for:

- short margin notes
- emphasis
- route-like labels
- small poetic annotations
- one-off emotional marks

Should feel:

- fast
- imperfect
- human
- not polished calligraphy

### D. Body text

Use:

- readable serif or understated sans
- medium size
- generous line spacing
- low visual noise

Do not make body copy feel like a corporate report.

────────

## 5. Typography rules

1. Use only 2–3 typographic voices per piece.
2. Hero text should dominate clearly.
3. Supporting labels should feel archival.
4. Handwriting is seasoning, not the whole meal.
5. Avoid perfect baseline consistency in handmade sections.
6. Avoid excessive font variety.
7. Avoid tech-startup geometric sans-serif as the main voice.
8. Avoid glossy luxury typography.
9. Avoid fake "boho" script fonts.
10. Prefer raw editorial contrast over brand-polish consistency.

────────

## 6. Layout system

Layouts should feel composed but not rigid.

### Preferred structures

- torn-paper modular blocks
- asymmetrical editorial grids
- oversized headline + image
- stacked manifesto fragments
- image strip + text panel
- field-journal spread
- layered scraps / notes / labels
- large visual anchor with smaller supporting artifacts

### Spatial behavior

Allow:

- irregular margins
- slight overlaps
- controlled cropping
- torn edges
- tape
- uneven spacing
- asymmetry

But maintain:

- one clear focal point
- intentional hierarchy
- enough breathing room
- readable flow

> **Asymmetry with control.**

Do not let "handmade" become clutter.

────────

## 7. Paper and material language

Recurring materials:

- aged parchment
- kraft paper
- rough cream stock
- worn black paper
- masking tape
- faded map fragments
- notebook paper
- torn photo edges
- typed labels
- old receipts
- field notes
- stamped marks
- weathered leather
- canvas
- wood
- stone
- concrete

These materials should feel physical.

────────

## 8. Edge treatment

Edges should often feel:

- torn
- frayed
- irregular
- deckled
- imperfectly cut
- slightly worn

Avoid:

- perfect rounded cards
- perfect app-interface rectangles
- clean UI-style shadows
- pristine floating panels

If a rectangle appears, it should usually feel like paper, print, or a physical object.

────────

## 9. Texture

Texture is essential.

Use:

- grain
- paper fiber
- scratches
- faded ink
- dust
- foxing
- worn print
- subtle staining
- creases
- surface variation
- slight print misregistration

The texture should support atmosphere.

Do not cover every surface with maximal distress.

> **Touched, not destroyed.**

────────

## 10. Image treatment

Photography should feel:

- cinematic
- documentary
- witnessed
- intimate
- slightly moody
- warm
- natural
- lived-in

### Preferred subjects

- travel
- roads
- trains
- bus stops
- tunnels
- mountains
- city streets
- musicians in transit
- performance moments
- people eating / talking / gathering
- local culture
- gear in use
- field recordings
- journals
- guitar
- hands
- audience participation
- ordinary places with character

### Character posture

Ya Selva should look:

> **caught, not posed**

Preferred emotional modes:

- discovery
- witness
- transmission
- curiosity
- movement
- solitude
- contact
- awe

Avoid:

- influencer posing
- hero shots that feel self-important
- polished fashion-editorial posture
- mystical cosplay
- fake spiritual authority

────────

## 11. Image color behavior

Preferred:

- warm highlights
- muted saturation
- earthy greens
- deep blacks
- brown / amber shadows
- cinematic dusk / dawn
- natural skin
- restrained color

Avoid:

- neon digital gradients
- overly teal-and-orange blockbuster grading
- glossy HDR
- clean commercial travel photography
- oversaturated tropical tourism aesthetics

────────

## 12. The orange signal

The orange signal is the core recurring graphic motif.

Form:

- rough circular ring
- imperfect hand-painted or spray-painted appearance
- small off-center inner dot
- occasional drip
- never too mechanically perfect

Meaning:

- signal
- pulse
- trace
- breadcrumb
- presence
- evidence
- "something alive passed through here"

Use it:

- on walls
- on paper
- as a stamp
- in margins
- at corners
- as a route marker
- as a recurring visual breadcrumb

Do not overuse it.

It should retain mystery.

────────

## 14. Collage behavior

Collage should feel archival and tactile.

Use:

- torn photographs
- paper fragments
- maps
- handwritten scraps
- receipts
- ink marks
- natural materials
- documentary stills

Composition should feel:

- layered
- intentional
- slightly improvised
- imperfect
- personal

Avoid:

- perfectly balanced Pinterest collage
- decorative scrapbooking
- overly cute craft aesthetics
- random texture with no narrative purpose

Every fragment should feel like it belongs to the journey.

────────

## 15. Graphic composition rule

Every graphic should have one dominant idea.

Examples:

- THE PILGRIM
- FIND THE PULSE
- THE RIG DOES NOT GET BIGGER. THE WORLD DOES.
- SEARCHING FOR SOMETHING REAL
- THE FIRST PRACTICE IS RE-ENTERING THE WORLD

Everything else supports that one idea.

> **One page. One pulse.**

────────

## 16. Imperfection rules

Imperfection is a core design feature.

Allowed / encouraged:

- slightly crooked type
- uneven ink density
- imperfect spacing
- rough paper edges
- slight baseline drift
- mild image misalignment
- hand-drawn marks
- uneven tape placement
- subtle print wear
- non-uniform texture
- occasional asymmetry

Avoid:

- symmetrical AI-poster perfection
- immaculate spacing everywhere
- crisp digital cleanliness
- identical repeated modules
- obvious template behavior

Imperfection must look intentional enough to remain beautiful.

────────

## 17. What to avoid

Never drift into:

- slick corporate branding
- Canva-clean layouts
- app-dashboard aesthetics
- generic motivational posters
- hyper-polished startup branding
- glossy luxury
- travel influencer content
- festival-boho clichés
- fake shaman aesthetics
- excessive sacred-geometry symbolism
- generic "spiritual" branding
- clean wellness-brand minimalism
- hyper-digital futurism
- neon cyberpunk
- excessive gradients
- polished stock-photo look
- perfect symmetry
- sterile minimalism

The world should feel lived in.

────────

## 18. Relationship between myth and ordinary life

The design must hold both:

mythic meaning
and
ordinary material

For example:

A torn bus ticket can sit next to a sentence about destiny.

A dirty guitar can sit beneath a line about pilgrimage.

A train window can carry a line about searching for the heart of the world.

This tension is essential.

> **Mythic meaning. Ordinary evidence.**

────────

## 19. Relationship to Ya Selva character

The visual language should support the character:

- Pilgrim
- Explorer
- Bard
- Witness
- Musician

But the root archetype is:

> **The Pilgrim.**

The visual language should feel like the collected artifacts of that pilgrimage.

Not a fantasy of travel.

Evidence of a life being lived.

────────

## 20. Design test

Before approving any Ya Selva visual, ask:

1. Does this feel alive?
2. Does this feel touched by a human?
3. Does it feel like it came from the road?
4. Does it feel cinematic without becoming slick?
5. Does it contain one clear emotional center?
6. Does it feel witnessed instead of staged?
7. Is the orange signal used with restraint?
8. Could this plausibly exist as a physical artifact?
9. Does it avoid generic influencer / wellness / startup aesthetics?
10. Does it feel like Ya Selva without needing the logo?

If not, revise.

────────

## 21. Short AI generation prompt

Use this when generating new graphics:

> **Create a Ya Selva visual manifesto in a tactile, cinematic, handmade editorial-collage style. Use weathered parchment, kraft paper, charcoal-black fields, moss and rust earth tones, and restrained ember-orange accents. Combine oversized literary serif headlines, typewriter-style archival labels, sparse handwritten annotations, torn-paper modules, masking tape, route-map fragments, grain, worn print, and candid travel/music imagery. Keep the composition asymmetrical but controlled, mythic but grounded, poetic but human. It should feel like a field journal, travel artifact, and handmade manifesto from a wandering musician — never like a corporate brand, polished influencer post, wellness aesthetic, or generic social-media template. Make it feel touched, not polished.**

────────

## 22. Fast style shorthand

If context is limited, use:

> **Ya Selva style = cinematic field journal + worn editorial poster + handmade travel collage + ember-orange signal.**

────────

Not a brand asset.

Not content.

An artifact.
