# Ya Selva — The Field / Studio / Stage Loop

## The important idea

The portable rig should not be a miniature version of the full studio.

It should be a **different operating mode with the same musical DNA**.

That keeps the everyday practice alive because the field rig stays small enough to actually use.

> **Field mode is for discovery. Studio mode is for development. Full-rig mode is for embodiment and scale.**

The process is one continuous loop.

## Field mode — go out

Default everyday rig:

> **Ableton Move + phone + instrument + maybe mic / tiny mixer**

Possible instruments:
- guitar
- flute
- tiny percussion
- voice

Purpose:
- collect sounds
- sample the environment
- make beats
- improvise
- write fragments
- play with people
- record a pop-up performance
- discover what a place gives you

The point is not to bring the studio outside.

The point is to bring **just enough instrument** that the world can still get in.

> **Do not bring the studio into the world unless the music needs the studio.**
>
> **Bring something small enough that the world can still get in.**

## Studio mode — come home

The main production setup can stay assembled and ready:

- laptop
- interface
- Push 2
- monitors
- deeper production tools

This matters because the home studio should not have to be dismantled every time the field rig goes out.

The field material comes back to a studio that is already waiting.

Use studio mode for:
- arrangement
- editing
- sound design
- deeper recording
- vocals
- mixing decisions
- expanding the strongest field ideas

## Full-rig mode — take it back out bigger

When the material has earned more scale:

> **Ableton Live + Push 2 + interface + instruments + PA + guests / participation as needed**

At this point the extra complexity is justified because the song has already proven itself.

This can become:
- street performance
- ecstatic dance
- club set
- house concert
- festival
- larger stage

The material is not replaced.

It is expanded.

## The loop

> **GO OUT**
> Ableton Move / guitar / flute / percussion / phone
>
> ↓
>
> **FIND SOMETHING ALIVE**
> sound / groove / person / lyric / place / sample
>
> ↓
>
> **COME HOME**
> Ableton Live / full production setup
>
> ↓
>
> **BUILD IT**
> arrangement / sound design / vocals / editing
>
> ↓
>
> **TAKE IT BACK OUT BIGGER**
> Push 2 / instruments / PA / people
>
> ↓
>
> **LET THE WORLD CHANGE IT AGAIN**

Then the loop repeats.

## Governing principle

> **Start small enough to go. Keep the material portable. Expand only when the music asks for it.**

The studio provides depth.

Ableton Move provides contact.

Push 2 provides control and scale when the music deserves it.

The whole thing remains one process.
