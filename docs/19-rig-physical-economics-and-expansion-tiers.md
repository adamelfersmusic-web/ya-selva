# Ya Selva — Rig Physical Economics and Expansion Tiers

## Purpose

The Ya Selva rig should be designed around **physical economics**:

- weight
- size
- number of trips from the car
- setup time
- teardown time
- cable burden
- power burden
- body comfort
- transport friction
- how likely the setup makes you to actually leave the house

The goal is not maximum capability at every outing.

The goal is:

> **the smallest physical system that gives the musical capability the day actually needs.**

## Tier 0 — body + instrument

Possible:
- guitar
- flute
- tiny percussion
- voice
- phone
- journal

No electronics required.

This is the irreducible layer.

## Tier 1 — everyday field rig

> **Ableton Move + phone + instrument + tiny percussion + optional mic / tiny mixer**

This should be the default electronic outing.

Characteristics:
- internal battery
- minimal cables
- fits in backpack + guitar case
- almost no setup ritual
- easy to use for short spontaneous field trips

Power:
- Ableton Move internal battery
- phone internal battery
- optional small USB-C power bank

Body position:
- ground
- bench
- ledge
- existing table
- standing if desired

The field rig should not require furniture.

## Tier 2 — pop-up performance rig

> **Ableton Move + tiny front end/mixer + guitar + mic + phone + optional speaker**

Speaker option:
- Bose S1 when more projection is worth the carry

This creates a real pop-up performance system while remaining independent of wall power.

The phone can capture synced performance audio/video through the small front end where appropriate.

Possible add-ons:
- second phone for another camera angle
- tiny tripod
- compact sign / banner
- small power bank

## Tier 3 — expanded creative rig

> **laptop + Push 2 + interface + instruments + compact power solution**

This tier adds:
- deeper control
- more tracks
- more routing
- full Ableton Live
- more elaborate performance structure

But the physical burden rises:
- laptop
- Push 2
- interface
- extra cables
- power
- larger surface needs

Therefore Push 2 should appear only when the extra control is worth the added friction.

Power approach:
- laptop via high-output USB-C power bank when possible
- Push 2 via a small dedicated power solution
- larger battery station only when the outing is already intentionally expanded

## Tier 4 — local activation rig

This is where Ya Selva can deliberately bring more life into a place.

Possible:
- wagon / cart
- Bose S1
- duffel of handmade frame drums
- more tiny percussion
- blanket
- cushion
- water
- small folding surface
- larger battery
- compact sign / banner

The wagon matters because it changes the economics of carrying more gear.

Once the gear rolls instead of hangs from the body, a modest expansion stops feeling like punishment.

> **The wagon is not the base rig. It is a local expansion module.**

This is the tier where passing out ten frame drums and getting the block moving becomes realistic.

## Tier 5 — venue / festival

The venue provides much of the physical scale:
- PA
- subs
- power
- mixer
- lights
- stage
- engineers

Ya Selva brings the musical organism, not the entire venue.

> **The world around the rig gets bigger. The core rig does not need to become enormous.**

## Power as physical economics

Power should disappear into the appropriate tier.

Rule:

> **Every tier carries its own proportional power solution.**

- everyday field → internal batteries / small USB-C bank
- expanded Push 2 rig → compact dedicated battery solution
- larger local system → existing larger battery
- venue / festival → venue AC

Avoid making power its own luggage category.

## Body position as physical economics

Comfort affects how long the music stays alive.

Possible modes:
- ground + blanket / small cushion
- found surface
- standing
- tiny folding support only if actual use proves it matters

Rule:

> **Do not carry furniture unless the furniture meaningfully increases how long you want to stay and play.**

## The sign / banner

A recurring portable sign could become part of the rig.

Not a huge branded booth.

A small, durable visual marker that can travel everywhere and instantly makes a patch of ground feel like **a Ya Selva place**.

Possible forms:
- foldable fabric banner
- small roll-up sign
- lightweight painted board
- collapsible cloth flag
- handmade field sign with the orange signal mark

The sign should:
- pack small
- set up in seconds
- survive repeated outdoor use
- visually connect every pop-up performance
- feel like an artifact, not corporate signage

> **Set down the sign. Open the case. Start the pulse.**

## The physical-economics test

Before adding anything, ask:

1. How much capability does this add?
2. How much weight does it add?
3. How many new cables does it add?
4. Does it require AC power?
5. Does it require its own case?
6. Does it require furniture?
7. Does it make setup feel like a gig?
8. Will I actually use it often enough to justify carrying it?

The best addition is usually:

> **major capability, almost no added footprint.**

## Governing idea

> **The rig should expand by modules, not by becoming permanently heavy.**

Take only the layer the day asks for.

## Dependency friction

Physical economics is not only about pounds, dimensions, or number of bags.

A major hidden variable is:

> **dependency friction — how many separate things have to become operational before music can start.**

This matters when comparing rigs.

A laptop + Push 2 setup may not be dramatically heavier than a standalone device, but it introduces more dependencies:
- laptop
- Push 2
- power
- USB
- interface / routing as needed
- session state

A future Push Standalone rig could therefore be **more portable in practice** even if it is physically larger than Ableton Move, because it collapses the live brain into one object.

Possible future tier:

> **Push Standalone + instrument + mic / tiny mixer + phone**

Role:
- deeper than Ableton Move
- lower dependency burden than laptop + Push 2
- suited to developed pop-up performance, longer improvisational sets, ecstatic-dance material, and more elaborate live work

Ableton Move should remain the default minimum-friction field tier unless real use proves otherwise.

## The bag as behavioral infrastructure

A crucial part of physical economics is not merely what the rig contains, but **where it lives between outings**.

The field rig should have a permanent home:

> **The field rig lives in the bag.**

The goal is to eliminate pre-departure scavenger hunts and setup decisions.

Whenever possible, essentials should either:
- live in the field bag permanently, or
- have a dedicated duplicate that lives there

Examples:
- USB / audio cables
- adapters
- charger / power bank
- mic cable
- headphones
- small tripod / phone mount
- tiny mixer or front end
- notebook / pen

The home studio should remain assembled. The field bag should remain packed.

> **Do not cannibalize the field bag to run the studio.**

This turns departure into:

> **grab bag → grab guitar → leave**

If Push 2 is being taken outside during the current proving phase, it should have a protective sleeve / case appropriate to regular transport. Expensive gear that feels vulnerable creates its own hidden friction.

Eventually, a standalone Ableton brain could reduce the field system further, but the immediate behavioral principle stays the same:

> **Make the ready state the default state.**
