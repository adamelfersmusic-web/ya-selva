# Studio Fabric Spec — the textile shell

Spec. 2026-08-29.

Buying spec for the fabric that lines the Ya Selva studio. Reference image:
`images/mockup-studio-fabric-backdrop.png`.

The goal is not "green walls." The goal is a dark, matte textile shell that kills the
basement-white feeling, absorbs light and some reflections, and lets the banner,
lighting, plants, and gear emerge from darkness.

## Base wall fabric

**Color.** Near-black, desaturated forest green. Target neighborhood:

```
deep forest · blackened olive · very dark moss · very dark bottle green
```

Roughly `#101A14`–`#1B261C` as a visual target — but **don't buy by hex.** Fabric
changes dramatically under light. It should look almost black in dim light and reveal
green when warm or directional light hits it.

Avoid emerald, hunter green that reads obviously green, blue-green teal, saturated
jungle green, or anything bright.

## Material

Best choices, roughly in order:

| material | note |
|---|---|
| cotton velvet / velour | beautiful depth if affordable |
| duvetyne / commando cloth | excellent light absorption, very studio-friendly |
| heavy matte cotton | |
| cotton canvas | |
| heavy linen/cotton blend | |
| moving blankets | hidden behind decorative fabric where cost matters |

**Absolutely avoid:** satin, silk-look fabric, shiny polyester, thin synthetic
curtains, crushed velvet with sparkle, anything with a reflective finish.

**The sheen test.** Shine a phone flashlight across it from the side. If you get a
conspicuous bright streak, don't buy it.

## Wall plan

**Back wall / desk wall.** Deep near-black forest green, preferably mostly solid.
This is where the large Ya Selva fabric banner goes. The banner is the
highest-contrast, highest-information textile in the room.

**Side walls.** Either blackened green, charcoal-black, extremely dark indigo, or a
mixture. Pattern is absolutely allowed — mudcloth-inspired, woven geometric,
block-print — but it must be low contrast. From 8–10 feet away the pattern should
largely disappear and read as texture.

```
PATTERN CAN BE COMPLEX. CONTRAST CANNOT.
```

| | |
|---|---|
| black cloth with dark charcoal marks | yes |
| dark indigo with muted black pattern | yes |
| black with bright cream tribal pattern | no |

## Acoustic / physical spec

Favor heavy fabric with actual mass rather than thin decorative cloth.

Hang it with some looseness rather than stretching it completely flat. A little
pleating creates more depth and increases effective surface area. If possible, leave
a small air gap behind it.

In corners, use substantially deeper folds/bunching or conceal proper broadband
absorption behind the textile. Fabric by itself mainly helps higher-frequency
reflections; **it is not a substitute for bass traps.**

## Visual hierarchy

The room should read approximately:

```
70–80%   near-black / forest / charcoal
10–20%   natural brown / wood / woven neutrals
small    controlled accents of burnt orange / ochre / amber
tiny     teal — and only when created by lighting
```

The banner gets to shout. The walls don't.

**Don't try to match every green.** Slight variation among blackened forest, olive,
charcoal, and indigo makes the room feel collected and organic rather than like you
ordered a matching "jungle studio" set.

## Order a swatch first

Always, if the vendor allows it. **Half Price Drapes offers free fabric swatches** —
which is exactly right here, because the question we care about is

```
DOES THIS DISAPPEAR TOWARD BLACK UNDER LOW LIGHT?
```

not what the product page calls the color. Product photography is shot bright and
flat, which is the one lighting condition this room will never be in. A name like
"forest" or "olive" tells you nothing about how the cloth behaves at 8pm with two
lamps on.

What to do with the swatch when it arrives:

1. **Low-light test.** Put it on the wall it's meant for, kill the overheads, run the
   room's actual lamps. Does it go near-black? That's the pass condition.
2. **Sheen test.** Phone flashlight raked across it from the side. Conspicuous bright
   streak = reject.
3. **Warm directional test.** Aim one warm light at it. The green/indigo should
   *emerge* — present but not announced.
4. **Side by side.** Hold candidates against each other and against the banner. The
   variation between them is the point; make sure it reads as collected, not clashing.

Judge the swatch in the room, at night, under the lights the room will actually use.
Never under daylight or a phone screen.

## Buying instruction

Hand this to whoever is sourcing:

> Heavy, matte, light-absorbing textile in near-black desaturated forest/olive green,
> charcoal-black, or extremely dark indigo. Natural-looking surface texture preferred.
> Low-contrast woven/printed patterns permitted. No sheen, no saturated greens, no
> bright contrasting patterns. Fabric should visually approach black in low light and
> reveal its color/texture under warm directional lighting. **Order free swatches
> before committing to yardage** — Half Price Drapes and similar vendors provide
> them at no cost, and the color name on the product page is not the spec.

That's the spec to actually buy against.
