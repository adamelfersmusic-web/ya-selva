# THE MAP — the facilitator network

**The single next action.** Zero creative energy required — it is recall, not invention.

```
without the map:  "one city this fall"          ← a wish
with the map:     "these 14, call Sarah first"  ← a route
```

## The terrain

**This community already exists.** It isn't a market to build — it's a network that's already
there, that Ya Selva is already part of, and that can be mapped from relationships you already
have.

```
Song Circles · Ecstatic Dance · Drum Circles · Cacao
Musicians · Producers · Dancers
Retreats · Conscious Community · Co-Ops
Other
```

These are not ten separate scenes — they're **one overlapping population.** The person running
the cacao ceremony knows the ecstatic-dance host, who books the drum-circle facilitator, who
lives at the co-op. Map one city and a few calls give you most of it.
**The map is a graph, not a list** — which is what makes it tourable.

## Split the roles — two different calls

```
HOSTS         Song Circles · Ecstatic Dance · Drum Circles · Cacao
              Retreats · Conscious Community · Co-Ops
              → they run the Gathering, they bring the room

CONTRIBUTORS  Musicians · Producers · Dancers
              → they run breakout rooms, or fill them
```

**Producers are the constraint, not hosts.** You need 3–4 per city who can run a room and
record cleanly. Hosts you have in abundance. A city with a great host and no producers can run
an Underpass — not a Moonlight.

**Co-Ops are the sleeper.** The only entry that's a *building* rather than a person. Multiple
rooms, often cheap or free, resident community, predisposed to say yes. For a format needing
3–4 separable spaces plus a main room, that's an unusually good match.

**Cacao is the freshness indicator.** Newest of these practices, so it maps where things are
*currently* active rather than where they used to be.

## The tiering — sort by drive time, not just warmth

```
TIER 1   ≤5 hrs  +  close/warm   →  DON'T MESSAGE. SHOW UP.
                                     attend their event, run twenty minutes,
                                     the conversation ends itself
TIER 2   >5 hrs  +  close/warm   →  trailer + the warm reach-out
TIER 3   cold or unknown         →  needs an intro or press first
```

The demo is free and portable — but only inside driving distance. That's the whole reason
drive time is a column.

## The method

```
1. Brain-dump. No structure. Every name that surfaces. Don't filter.
2. Go city by city — geography jogs memory better than category.
3. Scan Instagram followers/following, old event pages, festival lineups,
   tagged photos. Most of the map is already in your phone.
4. THEN sort into columns.
5. THEN tier it.
```

**Do not filter while dumping.** Filtering is what turns a 20-minute task into a three-week
one that never finishes.

## What "done" looks like

Done is not complete. Done is:

```
[ ] enough names to see whether this is a 5-city or a 30-city thing
[ ] at least 3 names in TIER 1
[ ] ONE name circled as the first call
```

The map grows forever. It only has to be good enough to make one call.
