# Ya Selva — Push Standalone as a Future One-Box Rig

## Why it is interesting

Push Standalone is worth keeping in view as a possible future Ya Selva upgrade because it addresses a specific kind of friction:

> **dependency friction**

The problem with a laptop + Push 2 rig is not necessarily weight. It is that multiple separate things have to become operational before the music starts:

- laptop
- Push 2
- cables
- power
- interface / routing as needed
- Ableton Live session

A slightly larger standalone instrument may actually feel **more portable in practice** if it collapses those dependencies into one musical object.

> **The real portability metric is not only pounds or dimensions. It is how many separate things have to become operational before music can begin.**

## Where Push Standalone could fit

The current architecture should remain:

### Everyday / field discovery

> **Ableton Move + phone + instrument + optional mic / tiny mixer**

Ableton Move remains compelling because it is the smallest, fastest, lowest-friction electronic field tier.

### Future deeper standalone tier

> **Push Standalone + instrument + mic / tiny mixer + phone**

Push Standalone could become the option for days when Ya Selva wants:

- deeper Ableton control
- more complex arrangements
- richer live manipulation
- a fuller standalone instrument
- no laptop dependency

This could be especially strong for:

- developed pop-up performances
- longer improvisational sets
- ecstatic-dance material
- more elaborate street / venue performances
- situations where Ableton Move feels too constrained but a laptop still feels like unnecessary friction

### Full expansion

> **Ableton Live + Push 2 / full studio and stage infrastructure**

The existing full rig remains useful when maximum flexibility, routing, editing, redundancy, or studio depth is needed.

## Ableton Move vs Push Standalone

They solve different problems.

### Ableton Move

Optimizes for:
- minimum friction
- tiny footprint
- field capture
- sampling
- sketching
- spontaneous outings

> **Ableton Move = minimum friction.**

### Push Standalone

Optimizes for:
- deeper performance
- more complete Ableton instrument behavior
- fewer dependencies than laptop + Push 2
- a one-box live brain

> **Push Standalone = maximum depth without the laptop.**

Neither needs to replace the other.

## Why not buy it immediately

The correct approach is still:

> **Start with what already exists. Notice the exact friction. Upgrade only when the friction becomes obvious.**

Use the current Push 2 + laptop rig and test Ableton Move as the field tier.

If repeated real-world use produces the same complaint:

> **"I want the depth of Push, but I hate needing the laptop."**

then Push Standalone becomes a justified upgrade rather than gear fantasy.

If the recurring need is instead:

> **"I just want the smallest possible thing I can throw in the bag and make music with."**

then Ableton Move remains the better answer.

## Governing principle

> **Choose the device based on the amount of musical depth the outing needs and the amount of dependency friction the body is willing to carry.**

The project is not defined by any one box.

The boxes are simply different scales of the same process.
