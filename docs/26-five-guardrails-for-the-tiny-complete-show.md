# Ya Selva — Five Guardrails for the Tiny Complete Show

> **Do not design a portable version of a big show. Design a tiny complete show that the world can expand.**

This means the smallest version of Ya Selva cannot feel like a compromise, demo, stripped-down fallback, or rehearsal for the "real" show.

The backpack-scale version has to already contain the actual art.

Bigger contexts should add dimensions, not supply missing legitimacy.

## 1. The core show must work completely alone

If no local musician joins, no dancer shows up, no elaborate production is available, and the venue contributes nothing beyond power and sound reinforcement, Ya Selva should still be able to make a genuinely compelling show.

The irreducible core is enough:
- guitar
- voice
- Ableton brain
- songs
- presence
- participatory method

> **The smallest version is not a reduced version. It is the complete organism at minimum scale.**

## 2. Expansion adds; it never rescues

A percussionist, choir, dancer, horn section, projection system, local field recording, or giant PA should never be required to make the set good.

They should make an already-good organism become something it could not have become alone.

> **Local collaborators expand the show. They do not rescue it.**

## 3. Carry the spine, source the body

Travel with the elements that define Ya Selva:
- songs
- arrangements
- sonic vocabulary
- rig
- participatory method
- identity

Let each place provide the body:
- musicians
- dancers
- rhythms
- voices
- rooms
- field recordings
- audience energy
- local culture

> **Same sound. Different body.**

The point is not identical replication city to city. The point is recognizable Ya Selva DNA inhabiting a different local body every time.

## 4. Never let production requirements make movement impossible

Every new piece of gear, infrastructure, personnel, or production burden has to earn its place.

If an addition suddenly requires:
- a truck
- multiple crew
- specialized furniture
- multiple extra cases
- long setup times
- complicated power
- fragile routing

then it needs to create enough artistic value to justify the loss of mobility.

> **The show must remain capable of moving.**

A plane, train, sidewalk, rooftop, forest, tiny club, or festival should all be reachable by the same underlying organism.

## 5. Every scale must be the same organism

The park version, street version, club version, city-collaboration version, and festival version should not feel like separate Ya Selva shows.

The same musical DNA should remain visible at every scale.

The festival does not replace the backpack show.

> **The festival amplifies it.**

The world around the rig gets bigger. The core does not need to become enormous.

## The test

When the architecture starts drifting, ask:

> **If everything disappeared except what I could reasonably carry, would the thing still be unmistakably Ya Selva and worth experiencing?**

If yes, the core is right.

Then everything else is upside.

Bogotá can add bodies and percussion.
Manila can add voices.
Lisbon can add another musical language.
A festival can add 30,000 watts and lights.

But none of those places are supplying the thing itself.

> **You brought the thing. The world supplies new bodies for it to inhabit.**
