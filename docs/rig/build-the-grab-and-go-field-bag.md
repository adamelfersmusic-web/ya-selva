# Ya Selva — Build the Grab-and-Go Field Bag

## Status

**Next step.**

The project is close enough to workable that the next move is not more architecture.

It is to make departure stupidly easy.

> **Build the bag. Put the rig in it. Keep it ready. Go use it.**

## The behavioral goal

The field system should live in one stable physical configuration between outings.

> **The field rig lives in the bag.**

The home studio stays assembled.
The field rig stays packed.
The guitar has its case.

Departure should become:

> **grab bag → grab guitar → leave**

The bag is not storage after the fact. It is part of the instrument.

## V1 — use what already exists

Do not wait for Ableton Move, Push Standalone, a perfect mixer, a perfect vocal chain, a custom sign, or the final power solution.

Build the first working version from existing gear.

Possible current V1:
- Push 2 + laptop
- compact interface / mixer already owned
- mic
- guitar
- phone
- tiny percussion as desired
- headphones
- only the cables actually required
- current power solution

If Push 2 is going into regular field use, get or use a protective sleeve / case that makes carrying it feel safe rather than precious.

Built-in Ableton effects are enough for the proving phase. The point is not final polish. The point is motion.

## Permanent-bag rule

Anything required for departure should either:
1. live in the field bag permanently, or
2. have a cheap dedicated duplicate that lives there.

Likely candidates:
- USB cable
- audio cable(s)
- mic cable
- adapters
- charger(s)
- power bank
- headphones
- tiny tripod / phone mount
- notebook / pen

> **Do not cannibalize the field bag to run the studio.**

Every missing cable creates another decision before leaving.

## First field test

Do not make the first outing a show.

Go somewhere easy and stay long enough to learn what the body and rig actually want.

The first few outings are for observing:
- what was annoying to carry?
- what took too long to connect?
- what never got used?
- what did you wish you had?
- did you want a table or was a bench / ground enough?
- did the battery situation matter?
- did you actually want the mic?
- did the laptop create meaningful friction?
- did Push 2 feel safe enough to transport?
- could you begin making music quickly?

Do not answer these questions in theory when the park can answer them in an afternoon.

## The field-day possibility

The deeper goal is not merely portable production.

It is a way of spending time where music can weave back into ordinary life.

A future park afternoon could look like:

> arrive
> make part of a track
> walk / move / train
> come back to the track
> play guitar
> hang out
> record a sound
> do another set of movement
> return to the music
> go home with something that did not exist before

Movement could eventually be almost frictionless too:
- bodyweight / calisthenics
- compact resistance bands
- walking
- mobility work

But do not turn this into another gear or optimization project.

The important idea is:

> **Music, movement, sunlight, wandering, and making can happen inside the same afternoon.**

And:

> **The rig is not only portable so music can travel. It is portable so music can rejoin the rest of life.**

## Do not overbuild V1

No requirement yet for:
- dedicated mic stand
- folding table
- wagon
- large speaker
- sign / banner
- Push Standalone
- Ableton Move
- final battery architecture
- final vocal processing chain

Those can appear only when actual use creates the need.

A tiny mic support, table, wagon, speaker, sign, or other module becomes justified when repeated field sessions prove that it meaningfully improves the experience.

## Success condition

The next stage is successful when leaving with the rig stops feeling like preparation for an event.

It should feel more like grabbing your keys.

> **The ready state is the default state.**
