# Ya Selva — The One Rig That Scales

## Purpose

This is the canonical reference for the Ya Selva performance / creation rig.

The point is simple:

> **The rig does not become a different rig as the project grows. The world around the rig gets bigger.**

Ya Selva should be able to move from a living room to a street corner to an ecstatic dance to a festival stage to Red Rocks without changing the core identity of the system.

The spine stays the same:

> **body + guitar + voice + Ableton brain**

Everything else is modular.

────────

## Level 0 — Root

### Where it works

- bedroom
- porch
- living room
- woods
- park
- train
- anywhere

### Rig

- guitar
- voice
- phone
- notebook

### What it means

This is Ya Selva in its irreducible form.

You can:

- write
- improvise
- record an idea
- photograph something
- capture a voice memo
- talk to someone
- make a song seed

If every electronic device disappeared, the project would still exist.

> **The project begins before the technology.**

## Level 1 — Field Rig

### Where it works

- woods
- hostel room
- train
- café patio
- Airbnb
- friend's house
- park
- anywhere you can sit down

### Add

- laptop
- 2-in / 2-out interface
- vocal or lapel mic
- headphones
- tiny MIDI / pad controller
- a few necessary cables
- external SSD
- cloud backup

### Core signal path

- Guitar → Input 1
- Voice → Input 2
- Everything else → Ableton

Inside Ableton:

- drums
- bass
- synths
- samples
- loops
- field recordings
- effects
- arrangement
- live looping

At this level Ya Selva can already make legitimate records almost anywhere.

> **One guitar. One voice. One backpack. A studio anywhere.**

- town square
- rooftop

## Level 5 — Major Stage / Red Rocks

### What changes

Mostly resilience and scale — not the artistic architecture.

Potential additions:

- backup laptop
- redundant Ableton system
- larger interface
- wireless vocal
- wireless guitar
- MIDI foot control
- live percussionist
- guest musicians
- local collaborators
- visual operator
- lighting cues
- crew
- redundant power / playback

But philosophically:

> **Nothing changed.**

You could still begin a song alone with one guitar.

You could still sample somebody from the city that afternoon.

You could still loop them.

Then ten thousand people could sing over it.

> **living room → sidewalk → ecstatic dance → festival → Red Rocks**

Same person.

## Design Law

The smallest version must naturally grow toward the biggest version.

Do not build separate rigs for separate identities.

Build one organism that accepts modules.

### The test

Before adding any piece of gear, ask:

1. Does this make the project more alive?
2. Does this expand what the same core rig can do?
3. Is it worth the weight and setup friction?
4. Can it remain optional?
5. Does the smallest version still work without it?

If not, do not add it yet.

────────

The equipment exists to serve the life.

## Ableton Move-First Everyday Rig

The everyday Ya Selva rig should be Ableton Move-first, not laptop-first.

For ordinary wandering, field capture, pop-up performance, and low-friction creation, the base electronic stack becomes:

> **Ableton Move + tiny front end/mixer + guitar + mic + phone**

Optional:

- flute
- tiny percussion
- small speaker
- power bank

The important shift is this:

> **Ableton Move is not a separate mini-version of the project. It is the first stage of the same musical process.**

Material can begin anywhere:

- sample the environment
- build a beat
- capture guitar or voice
- sketch the harmonic or melodic idea
- perform it immediately
- record a synced phone performance

Then the same musical material can move upward into Ableton Live and Push when the music asks for more depth.

### One continuous process

> **Ableton Note → Ableton Move → Ableton Live + Push → ecstatic dance / full live set / festival**

These are not separate workflows.

They are not separate identities.

There is no hard divide between "demo mode" and "real music."

It is one organism gaining resolution and scale.

### Everyday mode

> **Ableton Move + guitar + mic + phone**

Small enough that going out still feels easy.

### Pop-up performance mode

> **Ableton Move + tiny mixer/front end + guitar + mic + phone + speaker**

This allows a real live performance to happen with almost no infrastructure.

The phone can capture finished stereo audio already synced to video.

Multiple phone angles or repeated takes can be cut around the same tempo and arrangement grid.

### Build-out mode

> **Take the same material into Ableton Live + Push.**

Now add:

- deeper arrangement
- more tracks
- stems
- additional percussion
- field recordings
- guests
- longer transitions
- live looping / clip structure
- more sophisticated performance control

### Ecstatic dance / larger-show mode

By the time Push and the full Live rig appear, the project has not changed direction.

The small field sketch has simply expanded into the larger embodied version.

> **The everyday street version and the ecstatic-dance version are the same process at different scales.**

The governing principle:

> **Start small enough to go. Keep the material portable. Expand only when the music asks for it.**

And:

> **The rig does not become a different rig as the project grows. The same musical material gains more channels, more bodies, more amplification, and more space.**

────────

## Ready-State Law

The rig should not merely be portable. It should be **stored ready to leave**.

> **The field rig lives in the bag.**

Keep the home studio assembled. Keep the field system packed. Avoid borrowing the same essential cable or adapter back and forth whenever a cheap dedicated duplicate can remove the decision entirely.

The ideal transition remains:

> **grab bag → grab guitar → door closes**

During the current Push 2 + laptop proving phase, protect Push 2 with a transport-safe sleeve / case if it is going into regular field use. A device that feels too precious to carry is not functionally portable.

Future standalone tiers may reduce dependency friction further, but readiness is independent of the hardware choice.
